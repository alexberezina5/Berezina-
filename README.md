# Berezina-
ДЗ в ЦТ

Репозиторий содержит два задания, на Python: генератор случайных паролей и завозной Telegram-бот с локальной языковой моделью Ollama.

Задание 1. Генератор паролей
Программа генерирует случайный пароль заданной пользователем длины.
Возможности:
Запрашивает у пользователя длину пароля.
Использует английские буквы в верхнем и нижнем регистрах, а также цифры.
Случайным образом выбирает символы и объединяет их в пароль.
Выводит готовый пароль в консоль.
Используемые модули: random, string — стандартная библиотека Python.


Задание 2. Telegram-бот с локальной нейросетью
Второе задание представляет собой Telegram-бота, который генерирует ответы с помощью локальной языковой модели. Для реализации бота используется библиотека aiogram, а для генерации текста — Ollama с моделью Qwen 2.5 3B.
Возможности бота:
Начало и приветствие
/start
Небольшая помощь
/help
Ответы в стиле Нейрохама
/roast
Ответы в стиле ру рэпа
/swaga
Очистка контекста чата
/clear

Дополнительные особенности:
Последние сообщения передаются модели для сохранения контекста.
Длина сообщения ограничена 2000 символами.
При ошибке генерации бот посылает на 3 буквы.
Для обращения к Ollama используется интерфейс, совместимый с API OpenAI.

Стек
Python — язык программирования.
aiogram — взаимодействие с Telegram Bot API.
Ollama — запуск языковой модели локально.
Qwen 2.5 3B — модель для генерации текста.
OpenAI Python SDK — отправка запросов к совместимому API Ollama.
httpx — HTTP-клиент для асинхронных запросов.
python-dotenv — загрузка настроек из файла .env.
Docker и Docker Compose — контейнеризация и запуск приложения, если используется соответствующая конфигурация.

Установка и запуск

1. Нужно установить зависимости
Создай виртуальное окружение при необходимости и установи библиотеки:
pip install -r requirements.txt
В requirements.txt должны быть указаны aiogram, openai, httpx и python-dotenv.
2. Установи Ollama.
Скачай программу с официального сайта: https://ollama.com/
Загрузи модель:
ollama pull qwen2.5:3b
Убедись, что Ollama запущена и модель доступна.
3. Настрой Telegram-бота.
Создай бота через @BotFather и получите токен.
В корне проекта создайте файл .env:
BOT_TOKEN=your_telegram_bot_token
MODEL=qwen2.5:3b
OLLAMA_BASE_URL=http://127.0.0.1:11434/v1
Замени your_telegram_bot_token на настоящий токен.
4. Запусти бота.
python main.py
После запуска открой Telegram, найди своего бота и отправь команду /start.
Запуск через Docker
Если в репозитории присутствуют Dockerfile и docker-compose.yml, а конфигурация Compose включает Ollama, проект можно запустить командой:
docker compose up --build -d
Посмотреть логи бота:
docker compose logs -f telegram-bot
При первом запуске может потребоваться время на загрузку модели.
При запуске через Docker адрес Ollama должен указывать на сервис внутри Docker-сети, например http://ollama:11434/v1.

Используй .env.example с демонстрационными значениями.
Не открывайте порт Ollama в интернет без необходимости.
